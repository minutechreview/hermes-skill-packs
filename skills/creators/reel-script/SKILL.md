# Reel Script

## When to Use
- "Write me a script about X", "turn this article into a reel", "script this".

## Procedure
1. Read the source (link, notes or repo). Pull out only facts you can point to.
2. Check memory for the creator's voice notes (words they use, words they hate, how they open). Match them.
3. Pick a length: 30 s ≈ 75 words, 45 s ≈ 110 words, 60 s ≈ 150 words.
4. Write in this shape:
   - **Hook (first line)**: the offer or the surprise. No intro, no name.
   - **Context (1-2 lines)**: what it is, in plain English.
   - **Beats (3-4 lines)**: one idea each. Use numbers ("First… Second…") for tutorials.
   - **The catch (1 line)**: the honest limit, cost or risk.
   - **CTA**: "Comment WORD and I'll send you the link."
5. Under the script, list on-screen suggestions per beat (screen recording, text pop, zoom).
6. Read it out loud in your head. Cut any sentence over 20 words.

## Pitfalls
- Spoken words, not written words: "it's", not "it is". No brackets or URLs in the spoken lines.
- Spell out tricky names the way they should be said if it will be voiced by AI.
- Never claim you used something you didn't. Write "I've been using" only if the creator told you so.

## Verification
- Word count fits the length.
- The first line works with the sound off as on-screen text.
- There is a catch line and a CTA.
