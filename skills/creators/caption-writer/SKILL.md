# Caption Writer

## When to Use
- "Caption for this", "write the IG caption", "post copy for X and LinkedIn".

## Procedure
1. Get the script or a summary of the video. Ask for the comment keyword if there is a DM funnel.
2. Check memory for saved caption preferences (emoji use, hashtag count, sign-off).
3. Write per platform:
   - **Instagram**: hook line → 2-3 short fact lines → a short list if useful → the closing line from the video → CTA ("Comment WORD…" or "Send this to someone who…") → about 10 hashtags.
   - **TikTok**: 1-2 lines + 3-5 hashtags.
   - **X**: one post under 280 characters, no hashtags or one at most. Offer a 3-post thread if there's more to say.
   - **LinkedIn**: 4-6 short paragraphs, first person, what you learned, no hashtag wall.
4. Credit the original maker when the post is about someone else's project.

## Pitfalls
- Don't paste links into Instagram captions; they aren't clickable. Use the comment keyword.
- Keep facts identical to the video. A caption that says a different number than the video looks fake.
- No hype words (game-changing, revolutionary, insane).

## Verification
- Each platform version fits its length.
- The CTA keyword matches the one in the video.
