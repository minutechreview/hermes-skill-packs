# Repurpose Post

## When to Use
- "Turn this video into posts", "repurpose this", "get a week of content out of this".

## Procedure
1. Get the source text. For a video or podcast, transcribe it first (the bundled `youtube-content` skill works for YouTube links).
2. List every distinct idea in the source, one line each. Usually 5-10.
3. Map ideas to formats:
   - 1 carousel (5-7 slides, one point per slide)
   - 2 short reels (one idea each)
   - 1 X thread
   - 1 LinkedIn post (the lesson)
   - 2 story/poll prompts
4. Write each piece fresh. Reuse facts, never the same sentences.
5. Return a simple 7-day plan table: day, platform, format, hook.

## Pitfalls
- Don't pad thin source material. If there are only 3 ideas, make 3 pieces.
- Keep credit to the original creator if the source isn't the user's own.

## Verification
- No two pieces share the same hook.
- Every claim traces back to the source.
