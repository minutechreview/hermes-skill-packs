# Content Ideas

## When to Use
- "Give me video ideas", "what should I post this week?", "I'm out of ideas".
- After `ai-news-digest` when the user wants angles on a story.

## Procedure
1. Check memory first: the creator's niche, audience, platforms, and which past posts did well or badly. If none of this is saved, ask 3 quick questions (niche, audience, platform) and save the answers with the memory tool.
2. Pull 2-3 fresh inputs: today's news, a tool the user mentioned, a question their audience keeps asking.
3. Write 10 ideas. Mix these formats so they don't all look the same:
   - **Tool reveal**: "This free app does X."
   - **Problem → fix**: open on the pain, then the fix.
   - **Build log**: "I built X in a day, here's what broke."
   - **Myth vs fact**.
   - **Tutorial in 4 steps**.
4. For each idea give: a hook line (under 12 words), the format, why it fits this audience, and the comment keyword for a DM funnel if it has a resource.
5. Mark your top 3 and say why in one line each.
6. When the user picks ideas, save them to memory under "idea bank" with the date so you don't repeat them later.

## Pitfalls
- Don't pitch an idea that's already in the idea bank or was already posted.
- Hooks must open on the offer or the surprise, not on "Hey guys".
- Avoid hype words: game-changing, revolutionary, insane, unlock.

## Verification
- 10 ideas, at least 3 different formats, top 3 marked.
- Nothing duplicates the saved idea bank.
